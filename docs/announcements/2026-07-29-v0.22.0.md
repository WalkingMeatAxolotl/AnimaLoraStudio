评估独立成页：一次评估一个任务、可中断重试、带样图对比且大幅提速 · 测试页图片历史加载提速

### 新增

- **评估有了自己的页面，一次评估只占一个任务（#469）**
  项目概览新增「评估」标签页：在这里查看历史评估、发起新评估。评估不再挂在某次训练名下——训练完成后随时可以对输出目录里的 checkpoint 发起评估，跑多少次都行，历史结果全部保留，方便对比改配置重训前后的指标变化。

  - 此前一次评估会往队列里塞几百个小任务（每个 checkpoint 的出图和每个指标各占一个）；现在整个评估就是队列里的一个任务，进度和日志都在一处
  - 评估详情页分 概览 / 指标 / 样图 / 日志；训练任务详情里也能直接看到那次训练触发的评估结果
  - **样图对比矩阵**：评估中每个 checkpoint × 每张验证图出的样图排成网格，可缩放、拖动、全屏翻页、导出合图 PNG——选 checkpoint 不用只盯指标数字
  - 评估被取消或中途失败后可以**重试**，已完成的部分不会重跑
  - 训练配置的评估设置新增 checkpoint 采样：评一个跳过 N 个（默认 0 = 每个都评，与之前一致），最终权重始终参评
  - 升级后旧版评估留下的成串任务记录会自动清理：旧的指标结果仍能查看，但这些记录的运行日志不再保留

### 变更

- **Attention 后端选项「none」现在显示为「SDPA」（#472）**
  该选项实际使用的是 PyTorch 内置的 SDPA 注意力实现，并非「未启用」，此前的名字容易误解。只是显示名变化：已保存的配置和预设不受影响，无需操作。

### 改进

- **评估速度大幅提升（#470, #471）**
  出图阶段底模整场评估只加载一次，checkpoint 之间热切换 LoRA 权重（此前每个 checkpoint 都重新加载底模，21 个 checkpoint 约多花 10 分钟）；指标阶段 CLIP / DINO / CCIP / WD14 每个模型也只加载一次。checkpoint 越多，提速越明显。
- **测试页的图片历史加载明显变快（#475）**
  此前每次进页面都要重新扫描全部落盘图片，图片攒多以后（2000+ 张）要等一秒以上；现在改用索引，同规模下约快 14 倍。一次能列出的历史条数上限也从 500 提高到 2000，更早的图不再被截断。

### 修复

- **误开第二个 Studio 不再弄丢正在生成的图（#473）**
  此前不小心开了第二个 Studio，它虽然启动失败，但退出前会误删正在运行实例的出图缓存——之后生成的图会从右侧列表消失、预览一直提示缓存未就绪，只能重启恢复。现在同一数据目录同时只允许一个实例，后来者会在碰任何数据之前直接退出。
- **测试页 LoRA 选择器不再自动跳回（#474）**
  在已存有 LoRA 的槽位里切换项目 / 版本下拉后，1-2 秒内会被刷回原来的选择；现在停在你选的位置。
- **LoKr / LoHa 训练日志不再被 dropout 提示刷屏（#468）**
  这两种算法暂不支持普通 dropout（`lora_dropout` 设了也不生效），此前训练开头会连打约 280 行相同提示；现在合并成一行，并注明该参数未生效。
