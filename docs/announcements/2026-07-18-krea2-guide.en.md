Use Studio's project pipeline to train a **Krea 2** (12.9B single-stream MMDiT) LoRA end to end: install models, collect or import images, caption, train, and test the result. The output loads directly in ComfyUI. This guide covers the Krea 2 setup and model-specific training choices; see [Training tips → Krea 2 training (Chinese)](https://github.com/WalkingMeatAxolotl/AnimaLoraStudio/blob/master/docs/user-guide/training-tips.md#krea-2-训练) for the full parameter reference.

### Getting started

The GB figures below are weight-file sizes, not full-run VRAM. GPU tiers are starting references and need configuration-specific validation.

1. Go to the model download center under **Settings → Training** and grab the weights in the "Krea 2" section (governed by the Krea 2 Community License):
   - **Raw**: the training base model. bf16 (26.3 GB, for 32 GB GPUs) or **official fp8** (13.1 GB — the pick for 24 GB-class GPUs)
   - **Turbo**: optional distilled model for fast test generation (8 steps); also available in fp8
   - **Text encoder** (Qwen3-VL): bf16 (8.9 GB) or fp8 (5.2 GB), switchable via radio
   - The VAE is shared with Anima — no second download needed
2. On the training config page, switch **Model family** to Krea 2 — a confirmation dialog lists every path and default about to be recomputed; confirm and you're set. Anima and Krea 2 versions can coexist in one project.

### Training tips

- **Train on Raw, never on Turbo.** Turbo is a distilled inference model. When using official catalog entries without an explicit training-base override, new versions fall back from a Turbo default to Raw. Custom paths or renamed weights may not be recognized; check their purpose yourself. Raw-trained LoRAs can load on Turbo, but quality and suitable strength still need testing.
- **VRAM**: start with official fp8 on 24 GB-class GPUs; bf16 on 32 GB-class GPUs also needs peak headroom. These are not guarantees for every rank, batch, or caption length; see the small-GPU guide when memory is tight. Selecting an fp8 file is sufficient, with no extra switch. fp8 training requires `grad_checkpoint` (on by default; disabling it errors at startup), and DoRA is incompatible. LoRA / LoHa / LoKr / rs-LoRA have supported paths, but this guide's measurements do not cover every combination or imply equal VRAM costs.
- **Caption in natural language**: Krea 2 uses the Qwen3-VL text encoder, not the booru tag ecosystem. Use the **LLM tagger** for long descriptive captions; trigger words are injected into newly generated captions, not added to existing files that are skipped. Tag shuffle / keep tokens / tag dropout do not apply to Krea 2 and are hidden. Studio does not truncate at 512 tokens: later tokens still participate in training, subject to model context and available resources. Longer descriptions increase text-cache and VRAM costs; do not add irrelevant detail just to make them longer.
- **The defaults are the right starting point**: timestep sampling defaults to `krea2_shift` (resolution-aware dynamic shift, matching the official training recipe); sampler Euler + Simple, 28 steps, CFG 4.5; the text cache is on by default — all captions are pre-encoded at training start and the text encoder is then released. bf16 TE weights are about 9 GB; fp8 releases a different amount, and file size is not the full encoding peak.
- Use the general learning-rate, rank/alpha (default 32/32), and optimizer guidance as starting points, not as proof that the best Anima settings transfer to Krea 2.

### Generation & ComfyUI

- Switch the model family to Krea 2 on **Generate**. Recognized official Turbo weights default to 8 steps / no CFG; explicit parameters take precedence, and custom weights need manual checking. fp8 reduces weight residency. On 16 GB-class GPUs, start with **Settings → Generate → VRAM policy → Save VRAM**, add block swap as needed, and verify the full loading and generation path.
- Studio's **Euler + Simple** corresponds to ComfyUI's **euler + simple** names. Matching names does not guarantee bitwise-identical images across software versions, hardware, or workflows.
- **Generate** supports PEFT / comfy key formats for Krea 2 community LoRAs. Check the model family and adapter variant; this does not promise compatibility with every community file.

### If you only use Anima

Nothing to do — the default family is still Anima, and existing projects, presets, and workflows are unchanged.
