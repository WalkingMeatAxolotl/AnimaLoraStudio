任务日志全面翻新——统一视图 / 调试开关 / 一键诊断包 / 跟随界面语言 · LLM 打标预设导入导出 · 多项 Windows 训练修复

### 新增

- **全站日志统一为同一套视图，新增调试开关（#507 #508 #509）**
  训练、出图、打标、评估的日志现在是同一套体验：按时间 / 级别 / 来源分列显示，错误红色、警告黄色；调试细节始终有记录、默认隐藏，视图里点「调试」即可展开——排障不用重跑任务。全局默认在 设置 → 系统 → 日志「默认显示调试日志」。

  - 支持「加载更早」翻页、复制可见行、下载完整原始日志
  - 断线重连后自动补拉缺口，中间的日志行不再丢
  - 任务失败时的错误摘要改为取最后一条真实错误（含完整堆栈），不再是笼统的末尾几行
- **一键导出诊断包（#512）**
  任务详情页和 设置 → 系统 → 日志 新增「诊断包」：把任务日志、配置快照、环境信息和对应时间段的服务日志打成一个 zip，报问题时直接附上。常见密钥（api key / token 等）自动脱敏，发出前仍建议自己过目一遍。
- **LLM 打标预设可以导入导出（#518）**
  预设编辑弹窗新增「导出」：下载的 json 不含 API 信息（密钥 / 接口地址 / 模型列表），放心分享提示词配方。设置页预设列表新增「导入预设」：导入后直接打开编辑弹窗补自己的连接信息，不会改动打标页正在用的默认预设。

  - 删除预设、另存为副本现在有成功提示

### 变更

- **任务日志跟随界面语言，异常不再刷屏（#514 #516）**
  日志里的叙事行（加载进度、显存状态、步骤汇报等）现在跟随界面语言显示中文或英文；警告 / 错误等排障行保持英文，方便搜索和贴 issue（界面上的报错提示不受影响，仍是双语）。

  - 训练数值异常（如 NaN）此前最坏能刷几万行日志，现在首次全文、之后按 epoch 汇总一条；连续无有效更新会升级为一条错误
  - 一批「其实有兜底」的错误行按真实严重程度降为警告，成功结束的任务不再夹着红行
  - 正常停止出图后台进程不再显示黄色警告
- **标签词典的两个开关搬进设置，不再存浏览器（#510）**
  「在 chip 上显示翻译」「输入时自动补全 tag」此前存在浏览器里，换浏览器或清站点数据就会丢。现在与其它设置同源保存、一起备份迁移；已设过的值自动搬过去，无需操作。

### 修复

- **Windows 上多分辨率训练切桶后速度永久掉一半（#506）**
  开启 ARB 多分辨率训练时，第一次切换分辨率桶后显存被打满但不报 OOM，之后每步都在走共享内存、速度掉一半以上。现在切桶时主动归还上一个桶的显存缓存，速度保持不变。
- **Block 交换较多层数时启动即报 CUDA out of memory（#511）**
  这个报错跟显存无关：换出层锁定的内存被按 2 的幂向上取整，实际占用放大约 1.5 倍，在 32GB 内存机器上换出 28 层会撞上 Windows 只允许锁定一半物理内存的上限。现在权重按精确总量打包，实际锁定 ≈ 权重本身大小；真不够时报错会说清楚是内存锁定不足、该调小几层。
- **XY 对比网格不再被任务超时误杀（#513）**
  出图超时此前按整个任务计时，格子多、每格又要重载模型的 XY 网格即使健康推进也会撞线被终止。现在改为按单张图计时：每出一张图重置倒计时，只有单张图长时间无进展才判定卡死。
