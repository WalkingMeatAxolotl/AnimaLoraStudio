The RAM/VRAM guard is now off by default

### Changed

- **The RAM/VRAM guard is now off by default (#484)**
  The guard estimates whether memory will suffice from weight file sizes, and the estimate is conservative — machines with plenty of memory were often wrongly refused when starting training or generation. The guard is now off by default across training, AI-generated regularization sets, and test generation; turn it on explicitly if you want the protection.

  - **Upgrading resets the toggles to off**, including if you had turned them on before. To keep using the guard: re-enable it under **Settings → Training → Training parameters** for training, and **Settings → VRAM strategy** for test generation
  - The pinned-memory guard for block swap is unaffected and stays always-on (exhausting pinned memory can freeze the whole machine, and lowering the number of swapped blocks is the way out)
