title: 通用 LoRA 训练指南
---
这篇适用于 Anima 与 Krea 2：先建立可靠基线，再用版本对照逐步调数据和参数。模型族专属差异请继续查看“Krea 2 训练指南”；小显存用户再看“Krea 2 小显存训练指南”。

### 先确定训练目标

- 一次先训练一个清楚的目标：角色、服装、画风或概念。目标混在一起，caption 和结果都更难判断。
- 图片质量、构图多样性和 caption 准确度通常比单纯堆数量更重要。删除重复、严重压缩、错误主体和明显水印干扰。
- 为每个目标选择稳定的触发词。训练前先决定哪些特征应该由触发词吸收，哪些仍要写进 caption。
- Anima 常用结构化 tag；Krea 2 更适合自然语言长描述。不要把一个模型族的 caption 习惯直接套到另一个。

### 准备训练集

1. 在**训练集筛选**中只保留与目标一致且有足够变化的图片；需要客观评估时，留出没有参与训练的验证集。
2. **预处理**只解决明确问题：重复图先去重，尺寸不足再放大，主体构图不合适再裁剪。不要为了“全做一遍”反复损伤素材。
3. 在**打标**中先小范围试跑，检查打标器风格后再扩大范围。页面默认跳过所有已有 caption（不限人工），也不会为跳过的文件补触发词；先在标签编辑中检查或补充，需要重新打标才明确选择覆盖。
4. 在**标签编辑**中修正身份、服装、动作和场景错误，并统一触发词位置与 caption 风格。
5. **正则集**是可选项。角色或概念需要更清楚的触发词开关、或担心底模遗忘时再加入；正则 caption 不应包含训练触发词。

### 数据量、repeat 和总步数

- 不要把固定张数当门槛。10–30 张经过筛选、覆盖角度与构图变化的图片可以作为单角色或单一概念的小规模基线；不足之处应通过 checkpoint 对照发现，而不是先机械凑到 50 或 100 张。
- repeat 是文件夹的样本权重，不是“越大越学得好”。先从 `1` 开始，需要提高某一组的相对曝光时再试 `2` 或更高，并同时检查 epoch 和总步数；不要照抄 `repeat=10/20` 再叠加很多 epoch。
- 在训练页的**数据与训练规模**中检查有效样本、每 epoch 更新步数和最终总步数。不同模型族、adapter、batch 和梯度累积不能只按图片数横向比较。
- 本项目历史画风训练记录使用的图片数和更新步数跨度很大，说明更小的数据集可以工作，但 `done` 不能证明视觉质量。角色、画风都应较密保存 checkpoint，用固定条件挑选有效区间。

### 建立第一条基线

- 在训练页选择正确的**模型族**和对应 Raw 训练底模；不要用 Krea 2 Turbo 训练。
- 第一次先使用该模型族的默认配置和普通 LoRA，只改输出名、epoch 等与本次实验直接相关的字段。
- 不要同时改学习率、rank、优化器、采样分布和数据集。一次改一个主要变量，复制为新版本做对照。
- 预计步数是数据量、repeats、batch、梯度累积和 epoch 的组合，不是运行时长预测；提交前在数据分布中检查推导。
- `seed=0` 会在任务创建时随机一次后冻结。跨任务对照时分别固定训练、采样和验证划分 seed，并保留配置快照、当时的数据、底模与软件环境；非零 seed 不保证跨版本或硬件逐位一致。

### 训练中看什么

- 入队时**配置参数**会冻结；图片、caption、正则集不会。可以编辑下一轮配置草稿，但数据或 caption 对照应先复制版本，不要改动已排队或运行任务引用的素材。
- 在**任务详情**看实际配置、日志、进度和采样图；在**监控**页集中比较活动训练。
- Loss 用来观察趋势和异常，不等于视觉质量。固定 prompt 和 seed 比较相邻 checkpoint，更容易发现学习不足、过拟合或突然漂移。
- 发生 OOM 时，先减少 batch、开启 gradient checkpointing 或降低分辨率；Krea 2 再按小显存指南调整 fp8、Block 交换与测试显存策略。

### 完成后怎么判断

先核对有效更新步数与目标步数，检查日志中的 NaN/Inf、跳步和采样失败。`done` 只表示任务成功结束，不保证有效训练达到目标或模型质量合格；loss 曲线里的有限值也可能没有显示被跳过的异常更新。

1. 在**测试**页用相同底模、prompt、采样 seed、LoRA 强度和采样参数比较多个 checkpoint。
2. 对比“底模不挂 LoRA”“挂 LoRA 不写触发词”“挂 LoRA 写触发词”三组，检查目标是否学到及非触发偏移；正则集不保证触发词成为严格开关。
3. 学习不足时，先检查 caption 和数据覆盖，再考虑增加训练量或学习率；过拟合时减少训练量、降低学习率或补充多样数据。
4. 保留表现最好的 checkpoint 与对应任务快照。下一轮从这条基线只改变一个可解释变量。

完整参数范围、caption / 正则配合、优化器、故障判断和硬件建议见 [LoRA 训练技巧](https://github.com/WalkingMeatAxolotl/AnimaLoraStudio/blob/master/docs/user-guide/training-tips.md)。
