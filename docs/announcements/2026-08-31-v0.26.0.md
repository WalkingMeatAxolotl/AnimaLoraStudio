测试出图工作流升级——分层 LoRA 目录 · 统一 XY 轴编辑与侧栏 · Booru 画廊选图打标 · 修复多线程下载器损坏动态 zip

### 新增

- **分层 LoRA 目录统一浏览项目产物和外部目录（#523）**
  测试页现在按“项目 / 来源 → LoRA”两层展示 Studio 项目 checkpoint、默认 LoRA 目录和自定义目录，支持来源筛选、搜索、版本筛选和递归目录浏览；单击即可添加或移除。额外目录可在“设置 → 测试”中管理。
- **测试页可从 Danbooru / Gelbooru 画廊选图并打标（#525）**
  提示词分区新增“从画廊选取”：可按来源、分级、时间和 tag 搜索并分页浏览，选图后用全局 WD14、CLTagger 或 LLM 设置生成提示词，也可在打标成功后自动开始出图。远程图片通过 Studio 的限流代理和本地缓存加载，不会自动导入训练集。

### 变更

- **XY 矩阵改用统一轴编辑抽屉和分层导航（#524）**
  X / Y 轴类型、值列表、checkpoint 与 LoRA 强度轴集中到右侧抽屉，支持拖拽排序；单图和 XY 模式共用当前 LoRA 面板，生成按钮直接显示图片总数。已有生成配置、历史快照和矩阵坐标保持兼容。
- **提示词与配置抽屉重开后保留现场（#525）**
  LoRA、XY 轴、训练集提示词和画廊抽屉首次打开后会在当前页面会话中保留筛选、滚动和已加载结果；训练集提示词现在也可直接编辑并随生成配置保存。

### 修复

- **多线程下载器下载现场生成的 zip 不再损坏（#522）**
  项目导出、bundle 和任务输出 zip 现在会拒绝 Range 分块下载，避免 IDM、迅雷、Ghost Downloader 等工具把多次即时打包的不同文件片段拼在一起。导出文件也改为完成后原子落盘，中断时不会留下半截 zip。
