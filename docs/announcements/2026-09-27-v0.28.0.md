训练可选 Triton 实验通道 · 随机种子按任务冻结 · 项目批量管理 · 测试、队列、评估与监控体验升级

### 新增

- **公告中心新增可持续维护的“指南”分类（#595）**
  “指南”固定排在筛选首位，便于新用户和回访用户反复查阅；首批包括 Studio 页面与工作流导览、通用 LoRA 训练指南、Krea 2 训练指南和 Krea 2 小显存指南。指南使用稳定条目原地更新，不会长期置顶挤占当前迁移提醒。
- **LoRA / LoHa 可选择受限 Triton 实验后端（#568、#569、#572、#577）**
  在“设置 → 系统 → 环境”安装匹配版本后，可在高级训练配置中为普通 LoRA / LoHa 显式选择 Triton。训练前会在隔离进程验证 CUDA 路径，探测失败则回退到 Torch；默认仍是 Torch，实测未证明稳定提速，也不支持 LoKr、DoRA、T-LoRA、Ortho、adapter dropout 或 FlashAttention 组合。当前公开硬件验证只覆盖 Anima。
  - 新增可复现的 LyCORIS 基准工具，可生成独立 reference、重放数值结果并比较 Torch / Triton 训练吞吐；使用方法见 [LyCORIS 基准指南](https://github.com/WalkingMeatAxolotl/AnimaLoraStudio/blob/master/docs/user-guide/lycoris-benchmark.md)。
- **项目列表支持批量归档、恢复与永久删除（#591）**
  活跃项目和归档项目都有明确的批量选择模式；搜索或筛选会自动裁剪隐藏选择。永久删除前会说明不可恢复后果与任务档案保留边界，部分文件删除失败时只移除成功项目并保留失败项供重试。

### 变更

- **`seed=0` 现在按任务或比较组随机一次并冻结（#575）**
  新训练任务会分别冻结训练、采样和验证集 seed；普通批量出图逐张随机，XY 矩阵和同一评估会话则共享比较 seed。实际值写入任务快照、生成历史和 PNG metadata，Retry / 暂停恢复继续使用原值；显式非零 seed 的复现语义不变。详见[随机种子说明](https://github.com/WalkingMeatAxolotl/AnimaLoraStudio/blob/master/docs/user-guide/random-seeds.md)。
- **测试页减少重复操作并改进 LoRA 选择（#580）**
  画廊选图可开启“自动打标”，生成前先取得最新提示词；切换提示词、LoRA、参数 Tab 时保留当前抽屉。LoRA 项目与文件支持按活跃时间、创建时间、修改时间或名称排序，移除按钮也有更大的键盘可访问命中区。
- **队列和任务详情更可靠、更易扫读（#587）**
  加载失败、加载中与空状态现在明确区分并可局部重载；取消、删除、暂停、继续训练和全局调度挂起会先说明实际影响。任务信息按状态、时间、来源分组，移除虚假进度和不可靠的排队名次，并补齐键盘操作与来源链接。
- **评估创建后留在评估列表并提供明确任务入口（#593）**
  创建成功后不再自动跳转，当前列表会突出新会话；关联任务可通过“查看任务”进入。创建弹窗、指标面板和样图矩阵统一使用设计系统组件，并补齐 checkpoint 的选择与键盘焦点状态。
- **长任务日志与监控状态更准确（#590、#592）**
  日志默认显示最近 2000 行，“加载全部”会连续回溯到文件头并继续接收实时日志。Monitor 的完成、失败、取消和暂停时长会冻结在对应时间点，不再持续增长；颜色、焦点、间距和动画也与主题、密度及 reduced-motion 设置一致。

### 改进

- **阻断式界面的键盘与焦点行为更一致（#581、#582、#584–#586）**
  图片预览、Settings 抽屉和 LLM 预设编辑器现在会正确接管并返回焦点、圈定 Tab 导航，并避免在未完成的任务上叠加全局搜索。Settings 打开时的 Toast 仍能被辅助技术读取，LLM 预设删除与恢复也在同一弹窗内完成。
- **折叠侧边栏图标与全站语义样式进一步对齐（#579、#592、#593）**
  不改变既有信息架构，统一图标、只读标签、卡片、主题色和紧凑布局下的视觉表达。

### 修复

- **阻止 Triton 与 FlashAttention 的已知不兼容组合（#589）**
  表单会在选择 FlashAttention 时固定使用 Torch；手写 YAML 的冲突组合会直接拒绝，旧预设修复时保留 FlashAttention 并回退 Torch，避免训练实际反复降级到 SDPA。

### 升级提示

- 本版没有必须执行的数据迁移；照常停止运行中的任务、关闭 Studio，并在更新前备份 `studio_data/`。
- Triton 不会自动安装或启用。需要尝试时先阅读 [Triton 实验后端说明](https://github.com/WalkingMeatAxolotl/AnimaLoraStudio/blob/master/docs/user-guide/triton-backend.md)；追求稳定或严格重复性时继续使用默认 Torch。
- `seed=0` 的新作用域自动生效，无需改配置。需要跨任务严格复现时请填写非零 seed，并保存任务快照或生成 metadata。
