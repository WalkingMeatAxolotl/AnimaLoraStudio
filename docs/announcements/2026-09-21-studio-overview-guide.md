第一次使用 Studio，先从这篇认识各页面的职责，以及一条 LoRA 从素材到测试的完整路径。Studio 把项目数据、训练版本和运行任务分开管理：**项目保存素材，版本保存一套训练方案，训练任务保存一次运行的配置快照。**

### 全局页面

| 页面 | 用来做什么 |
|---|---|
| **项目** | 新建、搜索、归档和管理 LoRA 项目；进入项目后继续处理数据与训练版本。 |
| **队列** | 查看正在运行、等待、计划和已经结束的 GPU / 数据任务；进入任务详情查看日志、监控、配置快照与输出。 |
| **测试** | 加载底模与一个或多个 LoRA，做单图、批量或 XY 对比；也可从训练集、画廊或历史记录恢复提示词。 |
| **预设** | 管理可复用的训练配置模板。预设是新版本的起点，不会持续覆盖已经复制到版本里的配置。 |
| **监控** | 集中观察活动训练的 loss、学习率、进度和采样图。 |
| **设置** | 安装或选择模型，配置下载源、打标器、训练、监控、测试、页面与系统行为。 |
| **公告 / 指南** | 右上角铃铛内查看更新、迁移提醒和可反复查阅的指南；用“指南”筛选快速回到本页。 |

### 进入项目后

- **概览**：查看项目、版本、数据集和训练状态，并创建或切换版本。
- **数据集**：从 Danbooru / Gelbooru 下载，或导入本机图片和 zip；原始素材由项目内所有版本共享。
- **训练集筛选**：从原始素材挑选本版本要训练的图片，整理训练文件夹，也可留出验证集。
- **预处理（可选）**：去重、放大、裁剪和涂抹；修改的是当前版本的训练集，不会移动共享原始素材。
- **打标**：用 WD14、CLTagger 或 LLM 批量生成 caption，并设置触发词与覆盖策略。
- **标签编辑**：检查单图 caption、批量增删替换标签，确认训练信号符合目标。
- **正则集（可选）**：用底模生成或从 Booru 搜索正则图片，减轻遗忘并改善触发词开关效果。
- **训练**：从预设建立当前版本的私有配置，检查数据与预计步数，然后立即或定时入队。

### 项目、版本与任务不要混淆

- 一个**项目**对应一个角色、画风或主题，保留共享原始素材。
- 一个项目可以有多个**版本**，分别尝试不同筛选、caption、模型族或训练参数；版本之间互不覆盖。
- 点击开始训练后会生成一份**训练配置快照**。之后修改版本的配置参数，不会改变已经排队或正在运行的任务配置；**图片、caption 和正则集不随任务冻结**。
- 任务排队或运行时，不要修改同版本的训练素材。需要调整数据或 caption 时先复制版本，避免影响已提交任务。
- 排查时优先看任务详情里的配置、seed、日志和输出，不要只看当前版本草稿。复现还需保留当时的数据、底模与软件环境；旧任务可能缺少历史字段。

### 新用户的最短路径

1. 在 **设置 → 训练** 安装并选择要使用的模型族。
2. 在 **项目** 新建项目，导入或下载素材。
3. 跟随项目侧栏依次完成筛选、可选预处理、打标与标签检查。
4. 不确定是否需要正则集时可先跳过；训练配置先用对应模型族的默认值。
5. 入队后在 **任务详情** 看日志与采样图，完成后去 **测试** 比较 checkpoint。
6. 只改一个主要变量再开新版本，保留可解释的对照。

完整安装、模型下载和逐步操作说明见 [上手教程](https://github.com/WalkingMeatAxolotl/AnimaLoraStudio/blob/master/docs/user-guide/getting-started.md)。
